  2. Reporting a Vulnerability.

  Project saddle is proprietary and source-available for viewing only.
  Do NOT open a public GitHub issue for security vulnerabilities.

  Please report vulnerabilities privately via the repository's private
  security advisory feature or via email to the Licensor.

  Include:

    - Description of vulnerability
    - Steps to reproduce (without including exploit code that copies project code)
    - Potential impact

  3. No Permission to Test Beyond Viewing.

  You are NOT authorized to perform penetration testing, fuzzing, or
  active scanning against any deployment of saddle without prior written
  permission.

  4. Disclosure.

  We will handle reports confidentially and provide acknowledgment.
