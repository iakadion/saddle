# OpenCode Multi-Forge - Repo como Processador Virtual

## Conceito: Storage = RAM = CPU

> Memória RAM e armazenamento são a mesma coisa. A diferença é uso: uma guarda, outra processa. 
> Transformamos o lugar que guarda arquivo em lugar que processa arquivo.

### Como?

1. **Swap file**: `fallocate -l 16G /mnt/swapfile && mkswap && swapon` -> disco virou RAM
2. **tmpfs**: `mount -t tmpfs -o size=8G tmpfs /mnt/ramdisk` -> RAM virou disco ultra rápido
3. **ZRAM**: comprime RAM para caber 2-3x mais
4. **Repo como CPU**: GitHub Actions roda código, não só guarda. Cada `workflow_dispatch` é uma chamada de função serverless.

### Arquitetura Thin Client (V3)

```
[Browser - GitHub Pages 50KB] --light--> [GitHub API] --dispatch--> [Actions Farm]
  - Preview 256 bytes                         - 4 vCPU, 16GB RAM, ilimitado público
  - SHA256 via Worker                         - Storage transformado em RAM via swap
  - Terminal fake                             - Resultado commitado em docs/results/
  <--polling-- status + artifact download ------
```

### Multi-Forja = Ilimitado real

| Forja | Minutos | Storage | Como usar |
|-------|---------|---------|-----------|
| **GitHub Public** | Ilimitado (standard) | 500MB artifacts, 10GB cache/repo | Principal |
| **Forgejo Self-Hosted** | Ilimitado (seu hardware) | Ilimitado | Mirror do repo |
| **Gitea Self-Hosted** | Ilimitado | Ilimitado | Mirror |
| **Codeberg + Woodpecker** | Ilimitado FLOSS | 750MB soft, pede mais via issue | Backup open source |
| **GitLab Free** | 400 min/mês | 10GB por projeto | Fallback Pages |

**Farm:** Crie 100 repos `opencode-worker-N`, cada um com 500MB free = 50GB distribuído. Script `scripts/farm.py` dispara para o primeiro livre.

### Como usar

1. Deploy `index.html` no Pages
2. Configure token com `repo` + `workflow`
3. Arraste binário -> clica "Enviar para GitHub para processar"
4. O binário NÃO roda no browser, só preview. O Action roda pesado.
5. Resultado aparece em `docs/results/{job_id}/` e baixa automático.

### Estrutura

- `index.html` - V2 thin client GitHub only
- `index-v3-multi-forge.html` - V3 com Forgejo/Gitea/Codeberg/GitLab
- `.github/workflows/` - 5 workflows GitHub
- `.forgejo/workflows/` - workflows Forgejo (swap + tmpfs)
- `.gitea/workflows/` - idem Gitea
- `.woodpecker/` - Codeberg Woodpecker CI
- `.gitlab-ci.yml` - GitLab CI
- `scripts/storage-as-ram.sh` - transforma storage em RAM
- `scripts/farm.py` - orquestra N repos

### Por que não pesa o navegador?

- Browser: só File API slice + base64 chunked + fetch
- Heavy: acontece em `/mnt/ramdisk` dentro do runner, com swap de 16GB
- Resultado: commitado no repo, Pages serve como CDN

Sensação: usuário mexe no binário normal, exporta normal, mas processamento é no repo.
