## EIXO 2A: Tiny AI — IA de 1TB em chip de 4GB

Este é o exemplo que você deu — totalmente real hoje.

| Projeto | Repo | Estrelas | O que prova |
|---|---|---|---|
| **llama.cpp** | https://github.com/ggml-org/llama.cpp | 109k+ | C++ puro que roda Llama 70B em laptop com quantização 4-bit (Q4_K_M). Formato GGUF reduziu de FP16 para 4-bit sem perder muito. Comando: `./llama-cli -m Llama-3-8B-Q4_K_M.gguf` |
| **Microsoft BitNet b1.58 / bitnet.cpp** | https://github.com/microsoft/BitNet | 38k | Primeiro LLM 1-bit treinado do zero: pesos só {-1,0,1} = 1.58 bits. Paper *The Era of 1-bit LLMs*. 2B treinado com 4T tokens. Roda 100B em CPU a 5-7 tok/s, 82% menos energia. `python setup_env.py -md models/BitNet-b1.58-2B-4T -q i2_s` |
| **WebLLM / MLC-LLM** | https://github.com/mlc-ai/web-llm | 15k | Roda LLM dentro do navegador com WebGPU, zero servidor. `npm install @mlc-ai/web-llm` — ChatGPT offline. |
| **QORA LLM 2B + QR executable** | https://github.com/qora-protocol/QORA-LLM-2B | — | Experimento de LLM dentro de blockchain QORA e discussão de modelo em QR code. Combina com `llamafile` (https://github.com/Mozilla-Ocho/llamafile) — executável único que é LLM. `llamafile` é um arquivo que é ao mesmo tempo modelo + runtime: `./llava-v1.5-7b-q4.llamafile` |

**Timeline:** 2023 llama.cpp → 2024 BitNet 1.58 bits → 2025 WebLLM → 2026 1-bit em produção. É exatamente "IA de 1TB em 4GB".

**Produto YouTube:** "Coloquei ChatGPT dentro de um QR code" — usando llamafile + qrcode generator: modelo 2B quantizado em 1.58-bit = ~400MB, corta em pedaços de 3KB (limite QR) e reassembla via JS no navegador com WebLLM.
