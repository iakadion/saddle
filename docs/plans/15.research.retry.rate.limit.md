## 1. Pacotes de Retry

### 1.1 p-retry (Recomendado)

**Versão:** 8.0.0  
**Descrição:** Retry com suporte a AbortError e callbacks  
**Última atualização:** 2024

```javascript
import pRetry from 'p-retry';

// Uso básico
const result = await pRetry(async () => {
  const response = await fetch('https://example.com');
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  return response.json();
}, {
  retries: 3,
  factor: 2,
  minTimeout: 1000,
  maxTimeout: 10000,
  randomize: true,
});

// Com AbortController
const controller = new AbortController();
setTimeout(() => controller.abort(), 5000);

const result = await pRetry(async (attemptNumber) => {
  console.log(`Attempt ${attemptNumber}`);
  
  const response = await fetch('https://example.com', {
    signal: controller.signal,
  });
  
  if (!response.ok) {
    throw new pRetry.AbortError(new Error(`Abort on ${response.status}`));
  }
  
  return response.json();
}, {
  retries: 5,
  onFailedAttempt: async (error) => {
    console.log(`Attempt ${error.attemptNumber} failed`);
    console.log(`Failures: ${error.retriesLeft}`);
    
    // Abort em caso de erro 401/403
    if (error.message.includes('401') || error.message.includes('403')) {
      throw new pRetry.AbortError(error);
    }
  },
});
```

**Configuração avançada:**
```javascript
import pRetry from 'p-retry';

const result = await pRetry(async () => {
  // Lógica de retry
}, {
  retries: 5,                    // Número máximo de retries
  factor: 2,                     // Fator de backoff exponencial
  minTimeout: 1000,              // Timeout mínimo (1s)
  maxTimeout: 60000,             // Timeout máximo (60s)
  randomize: true,               // Adicionar aleatoriedade
  signal: controller.signal,     // AbortSignal
  onFailedAttempt: async (error) => {
    // Callback após cada falha
    console.log(`Attempt ${error.attemptNumber} failed`);
    console.log(`Retries left: ${error.retriesLeft}`);
  },
});
```

```javascript
// Com retry callback
const result = await retry(async (bail) => {
  // Lógica de retry
}, {
  retries: 5,
  onRetry: (error, attempt) => {
    console.log(`Attempt ${attempt} failed, retrying...`);
  },
});
```

```javascript
const operation = retry.operation({
  retries: 5,
  factor: 2,
  minTimeout: 1000,
  maxTimeout: 60000,
  randomize: true,
});

      throw new Error(`HTTP ${response.status}`);

    operation.stop();

    } else {
      console.log(`All retries exhausted`);
      throw error;
    }
  }
});
```

## 2. Comparação p-retry vs async-retry

### Tabela Comparativa

| Característica | p-retry 8.0.0 | async-retry 1.3.3 |
|----------------|---------------|-------------------|
| **Tipo** | ESM/CommonJS | CommonJS |
| **AbortError** | Nativo | Via bail |
| **Callbacks** | onFailedAttempt | onRetry |
| **Bail** | AbortError | bail function |
| **Signal** | AbortSignal | Não suporta |
| **Fator de backoff** | Configurável | Configurável |
| **Jitter** | Configurável | Configurável |
| **Última atualização** | 2024 | 2023 |
| **Manutenção** | Ativa | Estável |
| **Bundle size** | ~2KB | ~1.5KB |

### Quando Usar Cada Um

**Use p-retry quando:**
- Precisa de AbortController/AbortSignal
- Quer callbacks detalhados (onFailedAttempt)
- Usa ESM nativo
- Precisa de granularidade no controle de retry

**Use async-retry quando:**
- Prefere API com bail function
- Usa CommonJS
- Projeto já usa async-retry
- Não precisa de AbortSignal

## 3. Algoritmos de Rate Limiting

### 3.1 Token Bucket

**Como funciona:**
- Bucket contém N tokens
- Cada request consome 1 token
- Tokens são adicionados a uma taxa fixa
- Se bucket vazio, request é rejeitado

**Vantagens:**
- Permite bursts curtos
- Simples de implementar
- Baixa memória

**Desvantagens:**
- Não garante taxa suave
- Burst pode sobrecarregar sistema

```javascript
class TokenBucket {
  constructor(capacity, refillRate) {
    this.capacity = capacity;
    this.tokens = capacity;
    this.refillRate = refillRate; // tokens por segundo
    this.lastRefill = Date.now();
  }

  consume() {
    this.refill();
    if (this.tokens > 0) {
      this.tokens--;
      return true;
    }
    return false;
  }

  refill() {
    const now = Date.now();
    const elapsed = (now - this.lastRefill) / 1000;
    const tokensToAdd = elapsed * this.refillRate;
    this.tokens = Math.min(this.capacity, this.tokens + tokensToAdd);
    this.lastRefill = now;
  }

  getTokens() {
    this.refill();
    return Math.floor(this.tokens);
  }
}

// Uso
const bucket = new TokenBucket(10, 1); // 10 tokens, 1 por segundo

async function makeRequest() {
  if (bucket.consume()) {
    return await fetch('https://example.com');
  } else {
    throw new Error('Rate limited');
  }
}
```

### 3.2 Sliding Window Log

**Como funciona:**
- Mantém log de todos os requests no último período
- Conta requests no período atual
- Se count > limit, rejeita

**Vantagens:**
- Preciso
- Sem edge cases

**Desvantagens:**
- Alta memória (armazena todos os timestamps)
- Computacionalmente caro

```javascript
class SlidingWindowLog {
  constructor(windowSize, maxRequests) {
    this.windowSize = windowSize; // em ms
    this.maxRequests = maxRequests;
    this.logs = [];
  }

  isAllowed() {
    const now = Date.now();
    const windowStart = now - this.windowSize;

    // Remover logs antigos
    this.logs = this.logs.filter(time => time > windowStart);

    if (this.logs.length < this.maxRequests) {
      this.logs.push(now);
      return true;
    }

    return false;
  }

  getCount() {
    const now = Date.now();
    const windowStart = now - this.windowSize;
    return this.logs.filter(time => time > windowStart).length;
  }
}

// Uso
const limiter = new SlidingWindowLog(60000, 100); // 100 requests por minuto

async function makeRequest() {
  if (limiter.isAllowed()) {
    return await fetch('https://example.com');
  } else {
    throw new Error('Rate limited');
  }
}
```

### 3.3 Sliding Window Counter

**Como funciona:**
- Divide tempo em janelas fixas
- Conta requests em cada janela
- Estima contagem atual baseado na janela anterior

**Vantagens:**
- Balance entre precisão e performance
- Baixa memória
- Simples

**Desvantagens:**
- Não é 100% preciso
- Pode ter edge cases

```javascript
class SlidingWindowCounter {
  constructor(windowSize, maxRequests) {
    this.windowSize = windowSize;
    this.maxRequests = maxRequests;
    this.currentWindow = Math.floor(Date.now() / windowSize);
    this.currentCount = 0;
    this.previousCount = 0;
  }

  isAllowed() {
    const now = Date.now();
    const currentWindow = Math.floor(now / this.windowSize);

    // Nova janela
    if (currentWindow !== this.currentWindow) {
      this.previousCount = this.currentCount;
      this.currentCount = 0;
      this.currentWindow = currentWindow;
    }

    // Calcular contagem estimada
    const elapsed = now % this.windowSize;
    const weight = elapsed / this.windowSize;
    const estimatedCount = this.previousCount * (1 - weight) + this.currentCount;

    if (estimatedCount < this.maxRequests) {
      this.currentCount++;
      return true;
    }

    return false;
  }

  getCount() {
    const now = Date.now();
    const currentWindow = Math.floor(now / this.windowSize);

    if (currentWindow !== this.currentWindow) {
      return 0;
    }

    return this.currentCount;
  }
}

// Uso
const limiter = new SlidingWindowCounter(60000, 100); // 100 requests por minuto

async function makeRequest() {
  if (limiter.isAllowed()) {
    return await fetch('https://example.com');
  } else {
    throw new Error('Rate limited');
  }
}
```

### 3.4 Fixed Window

**Como funciona:**
- Divide tempo em janelas fixas
- Conta requests em cada janela
- Reseta contador no início da janela

**Vantagens:**
- Simples
- Baixa memória
- Rápido

**Desvantagens:**
- Edge cases no início/fim da janela
- Pode permitir bursts

```javascript
class FixedWindow {
  constructor(windowSize, maxRequests) {
    this.windowSize = windowSize;
    this.maxRequests = maxRequests;
    this.windowStart = Date.now();
    this.count = 0;
  }

  isAllowed() {
    const now = Date.now();
    
    // Nova janela
    if (now - this.windowStart >= this.windowSize) {
      this.windowStart = now;
      this.count = 0;
    }

    if (this.count < this.maxRequests) {
      this.count++;
      return true;
    }

    return false;
  }

  getCount() {
    const now = Date.now();
    if (now - this.windowStart >= this.windowSize) {
      return 0;
    }
    return this.count;
  }
}

// Uso
const limiter = new FixedWindow(60000, 100); // 100 requests por minuto

async function makeRequest() {
  if (limiter.isAllowed()) {
    return await fetch('https://example.com');
  } else {
    throw new Error('Rate limited');
  }
}
```

### 3.5 Leaky Bucket

**Como funciona:**
- Requests entram em uma fila
- Requests saem a uma taxa fixa
- Se fila cheia, request é rejeitado

**Vantagens:**
- Taxa suave e constante
- Sem bursts

**Desvantagens:**
- Alta latência
- Não permite bursts
- Complexidade

```javascript
class LeakyBucket {
  constructor(capacity, leakRate) {
    this.capacity = capacity;
    this.leakRate = leakRate; // requests por segundo
    this.queue = [];
    this.lastLeak = Date.now();
  }

  isAllowed() {
    this.leak();

    if (this.queue.length < this.capacity) {
      this.queue.push(Date.now());
      return true;
    }

    return false;
  }

  leak() {
    const now = Date.now();
    const elapsed = (now - this.lastLeak) / 1000;
    const leakCount = Math.floor(elapsed * this.leakRate);

    if (leakCount > 0) {
      this.queue.splice(0, leakCount);
      this.lastLeak = now;
    }
  }

  getQueueSize() {
    this.leak();
    return this.queue.length;
  }
}

// Uso
const bucket = new LeakyBucket(10, 1); // 10 capacity, 1 por segundo

async function makeRequest() {
  if (bucket.isAllowed()) {
    return await fetch('https://example.com');
  } else {
    throw new Error('Rate limited');
  }
}
```

## 5. Rate Limiting por Domínio

### 5.1 Implementação com Map

```javascript
import { RateLimiterMemory } from 'rate-limiter-flexible';

class DomainRateLimiter {
  constructor(defaults = {}) {
    this.limiters = new Map();
    this.defaults = {
      points: defaults.points || 100,
      duration: defaults.duration || 60,
      blockDuration: defaults.blockDuration || 0,
    };
  }

  getLimiter(domain) {
    if (!this.limiters.has(domain)) {
      this.limiters.set(domain, new RateLimiterMemory({
        points: this.defaults.points,
        duration: this.defaults.duration,
        blockDuration: this.defaults.blockDuration,
      }));
    }
    return this.limiters.get(domain);
  }

  async consume(domain, key = 'default', points = 1) {
    const limiter = this.getLimiter(domain);
    try {
      const res = await limiter.consume(key, points);
      return { allowed: true, remaining: res.remainingPoints };
    } catch (rejRes) {
      return { 
        allowed: false, 
        retryAfter: Math.ceil(rejRes.msBeforeNext / 1000),
        remaining: 0,
      };
    }
  }

  async reset(domain, key = 'default') {
    const limiter = this.getLimiter(domain);
    await limiter.delete(key);
  }
}

// Uso
const limiter = new DomainRateLimiter({
  points: 100,
  duration: 60,
});

async function fetchWithRateLimit(url) {
  const domain = new URL(url).hostname;
  const result = await limiter.consume(domain);

  if (!result.allowed) {
    console.log(`Rate limited by ${domain}. Retry after ${result.retryAfter}s`);
    throw new Error(`Rate limited. Retry after ${result.retryAfter}s`);
  }

  return await fetch(url);
}
```

### 5.2 Implementação com Crawlee

```javascript
class CrawleeDomainRateLimiter {
  constructor(limits = {}) {
    this.limits = limits;
    this.domainRequests = new Map();
    this.domainWindows = new Map();
  }

  getLimitForDomain(domain) {
    return this.limits[domain] || { requestsPerMinute: 60 };
  }

  async checkRateLimit(domain) {
    const limit = this.getLimitForDomain(domain);
    const now = Date.now();
    const windowStart = now - 60000;

    if (!this.domainWindows.has(domain)) {
      this.domainWindows.set(domain, []);
    }

    const requests = this.domainWindows.get(domain)
      .filter(time => time > windowStart);

    this.domainWindows.set(domain, requests);

    if (requests.length >= limit.requestsPerMinute) {
      const oldestRequest = requests[0];
      const retryAfter = Math.ceil((oldestRequest + 60000 - now) / 1000);
      return { allowed: false, retryAfter };
    }

    requests.push(now);
    return { allowed: true, remaining: limit.requestsPerMinute - requests.length };
  }
}
```

### Implementação de Decisão de Retry

```javascript
function shouldRetry(error) {
  // Retry em erros de rede
  if (error.code === 'ECONNRESET' || 
      error.code === 'ECONNREFUSED' ||
      error.code === 'ETIMEDOUT' ||
      error.code === 'ENOTFOUND') {
    return true;
  }

  // Retry em status codes específicos
  if (error.status) {
    const retryableStatuses = [429, 500, 502, 503, 504, 408, 409];
    if (retryableStatuses.includes(error.status)) {
      return true;
    }
  }

  // Não retry em erros de autenticação
  if (error.status === 401 || error.status === 403) {
    return false;
  }

  // Não retry em erros de validação
  if (error.status === 400 || error.status === 422) {
    return false;
  }

  return false;
}

    throw error;
  }

}, {
  retries: 5,

    if (!shouldRetry(error)) {
```

```javascript
async function fetchWithRetryAfter(url) {
  return pRetry(async (attempt) => {
    const response = await fetch(url);

    if (response.status === 429) {
      const retryAfter = response.headers.get('Retry-After');

        // 1. Número de segundos: "120"
        // 2. HTTP-date: "Wed, 21 Oct 2015 07:28:00 GMT"
        let delay;

        if (isNaN(retryAfter)) {
          // É uma data HTTP
          const retryDate = new Date(retryAfter);
          delay = retryDate.getTime() - Date.now();

          // É um número de segundos
          delay = parseInt(retryAfter) * 1000;

        await new Promise(resolve => setTimeout(resolve, delay));
      }
      
      throw new Error(`Rate limited (429)`);
    }

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    return response.json();
  }, {
    retries: 5,
    minTimeout: 1000,
    maxTimeout: 60000,
  });
}
```

```javascript
class RetryAfterHandler {
  constructor() {
    this.retryAfterCache = new Map();
  }

  async handleRetryAfter(request, response) {
    const retryAfter = response.headers.get('Retry-After');
    
    if (retryAfter) {
      let delay;
      
      if (isNaN(retryAfter)) {
        const retryDate = new Date(retryAfter);
        delay = Math.max(0, retryDate.getTime() - Date.now());
      } else {
        delay = parseInt(retryAfter) * 1000;
      }

      // Adicionar margem de segurança (10%)
      delay = Math.ceil(delay * 1.1);

      this.retryAfterCache.set(request.url, {
        delay,
        timestamp: Date.now(),
      });

      return delay;
    }

    return null;
  }

  getDelay(url) {
    const cached = this.retryAfterCache.get(url);
    if (cached && Date.now() - cached.timestamp < cached.delay) {
      return cached.delay - (Date.now() - cached.timestamp);
    }
    return null;
  }
}
```

```javascript
async function parseRetryAfter(response) {
  const retryAfter = response.headers.get('Retry-After');
  const xRetryAfter = response.headers.get('X-Retry-After');
  const rateLimitReset = response.headers.get('X-Rate-Limit-Reset');
  const rateLimitRemaining = response.headers.get('X-Rate-Limit-Remaining');

  // Prioridade: Retry-After > X-Retry-After > X-Rate-Limit-Reset
  if (retryAfter) {
    return parseRetryHeaderValue(retryAfter);
  }

  if (xRetryAfter) {
    return parseRetryHeaderValue(xRetryAfter);
  }

  if (rateLimitReset) {
    const resetTime = parseInt(rateLimitReset) * 1000;
    return Math.max(0, resetTime - Date.now());
  }

  return null;
}

function parseRetryHeaderValue(value) {
  if (isNaN(value)) {
    // HTTP-date
    const retryDate = new Date(value);
    return Math.max(0, retryDate.getTime() - Date.now());
  }
  // Seconds
  return parseInt(value) * 1000;
}
```

### 9.3 Exemplo Completo: Sistema de Retry com Circuit Breaker

```javascript
import pRetry from 'p-retry';

class CircuitBreaker {
  constructor(options = {}) {
    this.failureThreshold = options.failureThreshold || 5;
    this.resetTimeout = options.resetTimeout || 60000;
    this.state = 'CLOSED';
    this.failureCount = 0;
    this.lastFailureTime = null;
  }

  async execute(fn) {
    if (this.state === 'OPEN') {
      if (Date.now() - this.lastFailureTime >= this.resetTimeout) {
        this.state = 'HALF_OPEN';
      } else {
        throw new Error('Circuit breaker is OPEN');
      }
    }

    try {
      const result = await fn();
      this.onSuccess();
      return result;
    } catch (error) {
      this.onFailure();
      throw error;
    }
  }

  onSuccess() {
    this.failureCount = 0;
    this.state = 'CLOSED';
  }

  onFailure() {
    this.failureCount++;
    this.lastFailureTime = Date.now();

    if (this.failureCount >= this.failureThreshold) {
      this.state = 'OPEN';
    }
  }

  getState() {
    return {
      state: this.state,
      failureCount: this.failureCount,
      lastFailureTime: this.lastFailureTime,
    };
  }
}

      minTimeout: options.minTimeout || 1000,

  }

        const response = await fetch(url, options);

        if (!response.ok) {
          const error = new Error(`HTTP ${response.status}`);
          error.status = response.status;
          throw error;
        }

        return response.json();
      }, this.retryOptions);
    });
  }

  getState() {
    return this.circuitBreaker.getState();
  }
}

// Uso
const fetcher = new ResilientFetcher({
  failureThreshold: 5,
  resetTimeout: 60000,
  retries: 3,
});

try {
  const result = await fetcher.fetch('https://api.example.com/data');
  console.log('Success:', result);
} catch (error) {
  console.log('Failed:', error.message);
  console.log('Circuit breaker state:', fetcher.getState());
}
```
