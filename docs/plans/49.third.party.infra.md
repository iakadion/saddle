# V5 - Tudo em Terceiros, Nada na Sua Máquina

Buckets:
- Hugging Face: public best-effort ilimitado, 500GB por arquivo, CDN free
- Kaggle: 200GB por dataset, publico ilimitado, 10 datasets = 2TB
- Terabox: 1TB free por conta, 3 contas = 3TB, Rclone 70+ backends
- NPM: 250MB por pacote, jsDelivr CDN ilimitado
- Turso 9GB, Neon 0.5GB, Supabase 500MB

Arquitetura: Browser Pages (50KB) -> API terceiro -> Actions Runner Microsoft (terceiro) -> Storage terceiro (HF/Kaggle/Terabox/NPM) -> Repo terceiro

Nada self-hosted, tudo alocado em plataforma de terceiros.
