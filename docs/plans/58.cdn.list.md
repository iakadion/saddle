# 10 CDNs para publicar site e transformar file storage em compute runner

1. **jsDelivr** - NPM + GitHub, 50MB GitHub, 100MB NPM, banda ilimitada, purge via https://purge.jsdelivr.net/gh/user/repo@tag/file - O S3 pirata
2. **UNPKG** - NPM apenas, ~100MB, Cloudflare, ideal para config/json privado via pacote não listado
3. **esm.sh** - NPM, JSR, GitHub, sem limite hard, transforma TSX em JS na edge com ?bundle&min&target
4. **Skypack (deprecated, usar esm.sh)** - fallback
5. **cdnjs** - curado via PR, 50MB por arquivo, Cloudflare
6. **Statically** - GitHub + GitLab + Bitbucket, sem limite declarado, imagem CDN com ?w= & ?f=webp
7. **GCore CDN** - free tier 1TB/mês, edge compute
8. **Cloudflare R2** - S3 compatível, free 10GB storage, 10M ops, egress free ilimitado (vs S3 $23/TB)
9. **Backblaze B2** - S3 compatível, free 10GB, 1GB download/dia free
10. **Supabase Storage** - S3 compatível, free 1GB, 2GB bandwidth, serve via CDN

Bonus:
- Hugging Face Hub CDN free ilimitado egress
- Kaggle Datasets CDN 200GB por dataset público ilimitado
- Terabox via Rclone 1TB por conta x3 = 3TB

Uso como compute runner:
- Publica chunk como pacote NPM @seuuser/assets-001
- jsDelivr serve como CDN ilimitado: https://cdn.jsdelivr.net/npm/@seuuser/assets-001@1.0.0/dist/chunk.bin.js
- Site faz fetch do chunk, reconstrói binário em /mnt/ramdisk (tmpfs), executa
- File storage virou compute runner
