O que é parecido: os dois aplicam eletricidade no corpo por via periférica. A eletroacupuntura mesmo é definida como adaptação contemporânea da acupuntura tradicional que combina agulhas com eletroterapia moderna.

2. Brain to Query do Facebook — o que é e como funciona
O nome que viralizou como "brain to query" é na verdade Brain2Qwerty, da Meta FAIR + BCBL.

Histórico linear:

2017: Facebook Building 8 anuncia na F8 que vai digitar 100 palavras por minuto só com o cérebro, com 60 engenheiros dedicados a BCI não invasiva. A chefe Regina Dugan promete decodificar sinais do centro de fala a 100 wpm. 
2019: Meta compra CTRL-Labs, startup de pulseira que traduz sinais neuromusculares em comandos, por cerca de $1 bi. Depois disso, em 2021, Facebook anuncia que para de financiar BCI de leitura cerebral e foca em EMG de pulso, caminho mais próximo ao mercado. 
2021-2023: Stanford bate recordes invasivos: Handwriting BCI 90 caracteres/min com 94% de acurácia e depois Speech BCI com 62 palavras por minuto, 3x recorde anterior. 
2025-2026: Brain2Qwerty v1 publica em Nature Neuroscience. v2 em junho de 2026 introduz pipeline end-to-end que gera sentenças direto de gravação contínua MEG.
Como funciona o v2:
É um modelo em 3 estágios: (1) módulo convolucional que recebe janelas de 500ms de sinais M/EEG, (2) módulo transformer treinado em nível de sentença, e (3) modelo de linguagem pré-treinado para corrigir saída do transformer. 

Treinado com ∼22.000 sentenças de 9 voluntários, cada um com 10h de MEG usando scanner enquanto digitava. Ao invés de pipelines manuais, usa deep learning direto do sinal bruto para decodificar letras, palavras e sentenças completas. Resultado: 61% word accuracy média, até 78% no melhor participante. 

Repositório e docs que você pediu:

Resposta direta pros seus 2 problemas:

1. Dá pra usar GitHub / Hugging Face / GitLab como HD infinito?
Não do jeito que você pensou.

GitHub: arquivo máximo 50 MiB no browser e repo máximo 5GB, e eles bloqueiam push acima disso. A doc diz: "GitHub limits the size of files allowed in repositories. If you attempt to add or update a file that is larger than 50 MiB, you will receive a warning" e "Individual repositories capped to maximum of 5 GB". Eles ainda reservam direito de deletar repos com uso indevido 
Hugging Face: eles dão storage gratuito sim, mas para repositórios públicos da comunidade AI, e cobram para privados acima do free tier. Limite por arquivo hoje é 50GB, indo para 500GB. Usar como dump pessoal infinito leva a ban. 
Se você fizer pendrive que joga filme de 100GB no GitHub como se fosse HD, sua conta cai em 2 dias.

O que FUNCIONA de forma legal e já é usado pela Meta:

hf-mount — "Mount Hugging Face Buckets and repos as local filesystems. No download, no copy, no waiting". Ele usa FUSE e só baixa os bytes que você lê, com cache local. Comando: hf-mount start bucket myuser/my-bucket /tmp/data 
rclone mount — "mount any of Rclone's cloud storage systems as a file system with FUSE" 
nisten/huggingface-filesystem — sync de pasta pro HF sem usar disco local 
Isso te dá VHD (Virtual HD) sim, mas não VRAM.

2. Converter storage em VRAM / VGPU / VCPU?
Não existe conversão. VRAM é memória soldada na GPU com 900GB/s de banda. Storage remoto tem 100ms de latência. Você pode montar bucket como drive, mas processamento continua sendo local. É por isso que existe llama.cpp e BitNet — você baixa modelo do bucket via FUSE e roda local em CPU com quantização 1-bit.

3. Pendrive sempre conectado e "produzir internet via código 3G"?
Você citou um projeto que cria rede 3G via código. Existe: "Raspberry Pi is connected to an SDR device, which creates a signal that a cell phone can connect to" e RTL-SDR que faz "spoofing cell networks". Mas precisa de hardware SDR + amplificador + antena, e transmitir em frequência de operadora sem licença da ANATEL é crime telecom no Brasil. E mesmo criando a célula, você ainda precisa de backhaul de internet — a célula não cria internet do nada. 

Código puro não gera internet. O que produtos reais fazem: pendrive cria rede Wi-Fi HD-Infinito-Setup, você entra no portal 192.168.4.1 e digita senha da sua casa. Para ser "sempre conectado", coloca um dongle 4G com chip SIM do usuário.

Pluga → sobe AP de setup

App monta myuser/my-bucket como Z: no Windows
Você arrasta arquivo → vai pro bucket via FUSE (cache local)

Te dá HD virtual infinito dentro do ToS se usar Cloudflare R2 (10GB free legítimo), Storj, ou Hugging Face para modelos/datasets ML de verdade — não como lixeira genérica.
