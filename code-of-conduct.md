 Project: saddle

  1. Purpose.

  This Code of Conduct governs behavior in the Project saddle repository,
  issues, discussions, and any interaction related to the project. This is a
  proprietary, view-only repository.

  2. Expected Behavior.

    a) Be respectful and professional;
    b) Do not attempt to copy, redistribute, or misuse the source code;
    c) Do not spam, harass, or engage in disruptive behavior;
    d) Do not post exploit code derived from viewing the source.

  3. Unacceptable Behavior.

    a) Copying or forking for redistribution;
    b) Reverse engineering discussions;
    c) Unauthorized commercial solicitation;
    d) Discrimination, harassment, or hate speech.

  4. Enforcement.

  Violations may result in immediate ban from the repository, report to
  GitHub, and legal action for copyright infringement.

  5. Reporting.

  Report via private contact to the Licensor. Public issues for Code of
  Conduct violations should not include proprietary code.
